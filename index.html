How we build

Engineering principles, not slogans

The same four commitments run through every repository we publish.

Local-first & offline

The default path runs local models at $0 and stays on your machine. Cloud providers are optional, behind the same interface — never required.

Deterministic & verified

The same input compiles to a byte-identical, SHA-256-verified artifact. Reproducible by design — no hidden timestamps, no non-determinism.

Honest engineering

Docs are written against the source, not marketing. Every feature is labelled implemented, partial, or planned — we never claim a capability the code doesn't have.

Zero third-party deps

Pure Go standard library. A single static binary, auditable top to bottom, with a tiny attack surface and reproducible releases (SBOM + checksums).

Measured, not guessed

Routing and optimization decisions are driven by reproducible benchmarks on your data — a real feedback loop, not vendor priors.

Reliable by construction

Typed errors, bounded retries with jitter, timeouts, cancellation, and ordered fallback — failure handling is part of the compiled plan, not an afterthought.
